Abstract

CaterConnect is an AI-powered catering booking system that helps customers find and book suitable catering services based on their requirements. Customers can provide details such as event type, guest count, budget, cuisine preferences, date, and availability, and the system uses a central Agentic AI to provide personalized recommendations. The system follows a Service-Oriented Architecture (SOA), where major functionalities such as catering management, menu management, booking, payment, and notifications operate as independent services. As an additional sustainability feature, suitable surplus food remaining after an event can be registered and matched with suitable registered organizations, followed by donation notifications and pickup coordination. The project aims to make catering booking more intelligent while supporting the responsible redistribution of suitable surplus food.

Technology Stack

Backend: Java and Spring Boot
Database: MySQL
Architecture: SOA / Microservices with REST APIs
AI: LLM-based Agentic AI
